# motregen

Regen voor Nederland op [KNMI open data](https://dataplatform.knmi.nl/):
één tijdlijn van gemeten radar (history), via het operationele
KNMI-nowcastmodel (+2 u), tot HARMONIE-AROME (+2 dagen). Kaart met
WebGL-regenoverlay uit binaire dataframes, locatie-picker en een rain
intensity meter. Bestemming: **motregen.nl**.

Status: proposal-fase. Zie `.dev/proposals/` (MIP-1: architectuur,
MIP-2: frame-encoding) en `.dev/LOG.md` voor de actuele stand.
